# Humans to know skills

Practical skills for people working with AI agents. Each skill is a folder containing procedural instructions in `SKILL.md` and any supporting references.

## Skills

- [Jev Workflow Design](skills/jev-workflow-design): find a useful role for TypeSafe AI’s Jev in your workflow, define its inputs and fallback, and compare it with your current approach.
- [System One Model Evaluation](skills/system-one-model-evaluation): compare Jev, suitable open decision models, and your current approach on the same bounded task before changing production routing.

## Use a skill

Open the skill folder and load it through your agent’s supported skill mechanism. Preserve its relative file structure so referenced examples remain available. Read the instructions and requirements before running any workflow.

[Humans to know](https://www.humanstoknow.com) helps people discover and reuse skills for AI agents.
