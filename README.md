# Humans to know skills

Practical skills for people working with AI agents. Each skill is a folder containing procedural instructions in `SKILL.md` and any supporting references.

## Skills

- [Jev Workflow Design](skills/jev-workflow-design): find a useful role for TypeSafe AI’s Jev in your workflow, define its inputs and fallback, and compare it with your current approach.
- [System One Model Evaluation](skills/system-one-model-evaluation): compare Jev, suitable open decision models, and your current approach on the same bounded task before changing production routing.

## Muse Gadget SDK community recipes

These 43 device skills are derived from [Meta's open-source Muse Gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk/tree/468e5ba629f988ad107ba472555a8b632faac0d3). Humans to Know added repository setup context and task-specific preparation and verification guidance. Each package retains its Apache-2.0 LICENSE and NOTICE, including the original source and modification notice.

These are community recipes, not official Meta, Muse or device-vendor integrations. The Muse app, SDK token and runtime connection are required; the repository does not supply a supported self-hosted Muse service.
